# brand-covers

Text-free cover images (colors and symbols only) used as Notion page covers
for Nerdly's Futures Hub, path pages and brand cards. No names, plans or
numbers live here.

## Sector covers (`covers/sector-*.png`)

One cover per area of the business, for Nerdly OS hub pages, 📚 Library docs and
the Partner Knowledge Base. Same family as the desk/role art: navy field, plum
glow, neon heartbeat line, Celtic motif, a line-art glyph in the badge. Built by
`sectors/generate.py`.

| File | Used for |
|---|---|
| sector-ops | operating plan, daily rhythm, build logs, IDs & maps, OS hubs |
| sector-systems | HighLevel, Notion, tools, tech references |
| sector-bots | automations and bots ("how it works" pages) |
| sector-email | deliverability, Mailgun, InboxIQ, DNS, A2P/SMS |
| sector-onboarding | client and agency onboarding |
| sector-success | customer success, retention, scope, offboarding |
| sector-support | support SOPs, escalations, office hours |
| sector-training | staff training and the Academy |
| sector-client-kits | client-facing playbooks, workbooks and guides |
| sector-marketing | marketing, website, funnels, launches, events |
| sector-affiliates | affiliate program and partners |
| sector-finance | pricing, billing policy, rebilling (no figures) |
| sector-security | senior-staff, executive and access pages |
| sector-meetings | meeting hubs |
| sector-partner-kb | Partner Knowledge Base articles |

Brand pages keep `brand-nerdly`; retired pages use `team/covers/archive-2025`.
